# billing-schedule

Aplicación web (HTML, CSS y JavaScript puro) para gestionar los ciclos de facturación de tarjetas de crédito y saber qué tarjeta conviene usar cada día para tener más días de crédito sin intereses.

- **Hoy:** recomienda la mejor tarjeta según la fecha actual y ordena todas de mejor a peor.
- **Simular:** calcula qué tarjeta conviene para cualquier fecha de compra.
- **Calendario:** marca inicios de ciclo, cierres de facturación y fechas límite de pago.
- **Tarjetas:** agrega, edita o elimina tarjetas. Los datos se guardan en el LocalStorage del navegador.
- **Reglas de oro:** recordatorios para no pagar intereses.

## Uso

Abre `index.html` en el navegador. No necesita instalación ni compilación.

## Publicar en GitHub Pages

En el repositorio, entra a **Settings → Pages**, elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
